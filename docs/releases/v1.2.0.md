# v1.2.0 - Xen Orchestra 6.10 / REST API 0.41.1

Laravel Xen Orchestra now targets **XO 6.10.0 / REST API 0.41.1**, pinned to [commit b477167](https://github.com/vatesfr/xen-orchestra/commit/b477167b41f2ac401e7d8c852c139566b9fe756e).

- Manage plugins: list, inspect, configure, clear configuration, change autoload, load, unload and test.
- Discover NFS, ZFS, HBA and iSCSI storage from hosts through eight new probe helpers.
- Validate VMDK exports, new event collections and additional request fields through existing helpers.
- Extend the route inventory to 280 non-deprecated controller routes, preserving existing calls.

See the [XO 6.10 announcement](https://xen-orchestra.com/blog/xen-orchestra-6-10/) and the [1.2 usage guide](https://github.com/samuel-olavo/laravel-xen-orchestra/blob/v1.2.0/docs/usage-1.2.md).

Tests use a fake HTTP transport. No live-appliance integration test was performed; new features require server support and the appropriate permissions.

Thank you to the Vates and Xen Orchestra team for their work and for featuring this community package in the [XO 6.9 announcement](https://xen-orchestra.com/blog/xen-orchestra-6-9/), and to everyone sharing feedback and contributing improvements.
