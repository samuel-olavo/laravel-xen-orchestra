# v1.1.0 - Xen Orchestra 6.9 / REST API 0.40.2

This release updates Laravel Xen Orchestra for **XO 6.9.0**, targeting **REST API 0.40.2** at commit [`a2bd181`](https://github.com/vatesfr/xen-orchestra/commit/a2bd181d3528a61a45bbd4fe99686875fe8eebf8).

## What's new

- Mount and unmount backup disks as read-only storage through the live mount endpoints.
- Reclaim backup repository space, with optional VM selection and cleanup options.
- Read rolling pool update recovery records and finalize incomplete updates.
- Pass backup-check and baseline acceptance options while preserving existing rolling update/reboot calls.
- Verify QCOW2 disk/snapshot exports and the additional SSE collection types.
- Extend the pinned route inventory to all 264 non-deprecated controller routes.

Existing 1.0 calls remain compatible. New features require support from the server. Tests use a fake HTTP transport; no live-appliance integration test was performed.

See the [XO 6.9 announcement](https://xen-orchestra.com/blog/xen-orchestra-6-9/) for the upstream release and the [usage guide](https://github.com/samuel-olavo/laravel-xen-orchestra/blob/v1.1.0/docs/usage-1.1.md) for examples.
